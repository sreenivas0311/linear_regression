Overview

Implemented simple linear regression from scratch using Python and gradient descent to predict score from studytime. The model learns the slope (m) and intercept (b) to fit a linear relationship.

Dataset

Synthetic dataset with 100 points

Linear relationship: score = 2.5 * studytime + noise

Methodology

Defined a gradient descent function to minimize Mean Squared Error (MSE)

Iteratively updated slope (m) and intercept (b) for 1000 epochs

Results

Trained parameters: m ≈ 2.42, b ≈ 0.38

RMSE: ~1.99

The fitted line closely matches the data points

Conclusion

Linear regression from scratch successfully predicts score based on studytime

Gradient descent effectively minimizes error and fits the data
